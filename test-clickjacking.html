Prueba de Vulnerabilidad de Clickjacking (Iframe Embedding Test)

Simulación de Ataque Malicioso

Este archivo intenta incrustar la plataforma objetivo (https://lenios-front.vercel.app/) dentro de un <iframe> no autorizado para verificar la eficacia de las cabeceras de mitigación de Clickjacking (X-Frame-Options: DENY y Content-Security-Policy: frame-ancestors 'none';).

🔒 Si la página se muestra en blanco o el navegador reporta un error de bloqueo en la consola DevTools (refused to display in a frame because it set 'X-Frame-Options' to 'DENY'), la mitigación contra Clickjacking está ACTIVA Y FUNCIONAL.
